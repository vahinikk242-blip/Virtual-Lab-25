Aim

To develop a foundational understanding of cheminformatics by using computational tools to represent, visualize and analyze chemical structures.

🔤

SMILES notation

Convert molecules to and from SMILES text strings.

🧬

2D and 3D views

Visualize structures as skeletal drawings and rotating 3D models.

📐

Descriptors

Molecular weight, LogP, TPSA, HBD, HBA, rotatable bonds and ring count.

📈

Structure–property

Compare several molecules side by side and export a CSV table.

What can students do?

✅ Enter any SMILES notation

✅ Validate molecular structures

✅ Generate 2D structures

✅ Generate interactive 3D structures

✅ Choose visualization styles

✅ Calculate molecular properties

✅ Print or save a molecular report

✅ Compare multiple molecules

✅ Complete an assessment
